# npmjs-ci-testing

Canary consumer for the InditexTech CI governance **Node profile**. It exercises the
governed Node lifecycle — PR verification, release preview, CodeQL, SonarCloud,
Repo Linter/REUSE, and the release/publish lanes — end to end against real workspace
packages.

## Packages

- `@inditextech/release-test-core`
- `@inditextech/release-test-utils`
